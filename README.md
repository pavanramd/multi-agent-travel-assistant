# Multi-Agent Travel Assistant

An AI-powered travel planning application built using Python, Strands Agents, and Large Language Models.

## Project Overview

The goal of this project is to develop a multi-agent system where specialized AI agents collaborate to help users plan trips.

## Planned Features

- LLM-powered travel assistant
- Custom tools and function calling
- Weather and flight specialist agents
- Multi-agent orchestration
- Short-term and long-term memory
- Model Context Protocol (MCP) integration
- Agent-to-Agent (A2A) communication
- Agent evaluation and observability
- Safety and governance

## Technology Stack

- Python 3.12
- Strands Agents
- Groq
- MCP
- A2A
- Mem0

## Project Status

Under development.
